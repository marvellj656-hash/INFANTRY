基线提交：`7a3ac19`；基线标签：`pre-OMNI9_26`。标签保存用户上车状态和当时的 USB 时钟修改，并不代表全部功能已验证正常。旧 ELF 存在本地 `.migration-backup/pre-OMNI9_26/`，未跟踪进 Git。

本分支保留独立云台控制，不加入底盘跟随，不修改 Pitch 限位和 PID。

## 改动

- 修复 CAN 不同电机组复用同一硬件邮箱时误撤销对方报文的问题。BSP 记录每条总线每个邮箱的当前软件发送槽；只有仍属于自己的旧请求才允许撤销。保持唯一发送任务和非阻塞取消，不增加中断或任务。
- 增加“命令映射 → 发射控制 → 电机分组”的集成测试，覆盖关闭、disable、遥控离线、带转速反馈时零输出、到速门控、单发和连发。
- 发射阻断原因改用有名字的枚举，新增到速等待、堵弹锁存、输出提交失败的观测位；不放宽许可条件。
- 电机调试增加 HAL 接受的输出码和提交计数。它们不是总线 ACK 或电调执行证明。
- LinkScope 第 5 组增加实际转速，第 8 组检查关闭链路；提供两个直接双击入口，不必输入编号。
- 新增 `Docs/learning_start.md`，从一个动作解释接口、PID、NUC 阅读顺序和本次截图。
