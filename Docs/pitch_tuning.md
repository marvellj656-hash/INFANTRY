# Pitch调参：当前以RTT恢复版为准

先看 rtt_control_restore.md。本次撤回上抬2度、500ms归中、60度/秒满杆试验。
Task/gimbal/gimbal_config.h 的40个云台PID/限幅参数已逐项核对RTT。
PITCH_*_A_IMU：手动角度环，输入度、输出rad/s；PITCH_*_V_IMU：手动速度环，输入rad/s、输出电压码。
AUTO使用同名_AUTO组。不要把速度环输出上限与角度环目标速度上限混淆。

先用原参数对比实车，不同时调整多个增益。第16组看目标角度/反馈角度/误差；第17组看目标角速度/反馈角速度/输出。
归中后Pitch目标为INS 0度；机械归中编码器仍为3532。Pitch目标限位为INS -20..30度。
诊断pitch_output_limited在恢复版恒为0，因为额外编码器切输出逻辑已移除；保留字段只兼容现有观察表。
neutral仍表示遥控中位，但不再作为云台启动/恢复门槛。故障32/64不再用于等待中位/归中超时锁定。
真实命令失联、电机离线、IMU失效、发送故障仍可导致输出0，先看faults再判断PID问题。
